# Arounus Student for Android

Separate native Android project for the student learning area. It uses the existing HTTPS student API, which connects to the same production database. No database credentials are placed in the app. Market opens https://arounus.com in the device browser.

Open this folder in Android Studio, sync Gradle, and run the `app` configuration. For Play release, configure a signing key and build a signed Android App Bundle. Review the Play Console listing, data safety declaration, privacy policy, and account deletion requirements before submission.

The native implementation includes student sign in, registration, password reset, account profile editing, module enrollment, quiz lists and answer submission, lesson lists and video playback, results, messaging, and basic community posts. The debug APK compiled, installed, and launched in BlueStacks 5. Live sign-in, home, module enrollment, quiz catalog, empty lessons state, message inbox and composer all loaded with a student account. The Market button opened arounus.com in BlueStacks' browser. The test account had no available quizzes or lessons, so answer submission and video playback remain unverified. Features from the full student website such as live classrooms, media tools, premium video, and richer quiz content are still outstanding. A signed release bundle, Play listing, and policy disclosures also remain before Play submission.
