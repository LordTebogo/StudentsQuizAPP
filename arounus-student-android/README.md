# Arounus Student for Android

Separate native Android project for the student learning area. It uses the existing HTTPS student API, which connects to the same production database. No database credentials are placed in the app. Market opens https://arounus.com in the device browser.

Open this folder in Android Studio, sync Gradle, and run the `app` configuration. The GitHub workflow produces a debug APK and unsigned release Android App Bundle. The latest API 36 debug APK and locally signed release bundle are in `build/funquiz-final/`. The upload key and its Windows-protected password are outside the repository at `C:/Users/manyu/AppData/Local/ArounusAndroidTools/release/`. Back up both before publishing; future updates need the same upload key. The bundle signature was verified with `jarsigner`.

The app targets Android 16 (API 36). It includes an in-app account deletion request through the administrator inbox. The existing external request path is https://arounus.com/trust#popia; use that URL for Play Console's account deletion web resource after confirming its live wording and support contact. The privacy policy is at https://arounus.com/trust#privacy.

The native implementation includes student sign in, registration, password reset, account profile editing, module enrollment, standard quiz lists and answer submission, lesson lists and video playback, results, messaging, and basic community posts. Fun Quizzes have a dedicated one-question-at-a-time screen with level and progress, reading material and question images, instant checks, retries, explanations, similar questions, native spoken feedback with a sound toggle, pause and saved progress, and final result submission. The UI has a dark, luminous dashboard, bottom navigation, styled forms and cards, and clear empty states. Quiz lists are fetched from the existing student API each time they open, so quizzes published by a tutor for enrolled modules appear without an app update.
