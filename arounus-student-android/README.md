# Arounus Student for Android

Separate native Android project for the student learning area. It uses the existing HTTPS student API, which connects to the same production database. No database credentials are placed in the app. Market opens https://arounus.com in the device browser.

Open this folder in Android Studio, sync Gradle, and run the `app` configuration. The GitHub workflow produces a debug APK and unsigned release Android App Bundle. The API 36 debug APK and a locally signed release bundle are in `build/api36/`. The upload key and its Windows-protected password are outside the repository at `C:/Users/manyu/AppData/Local/ArounusAndroidTools/release/`. Back up both before publishing; future updates need the same upload key. The bundle signature was verified with `jarsigner`.

The app targets Android 16 (API 36). It includes an in-app account deletion request through the administrator inbox. The existing external request path is https://arounus.com/trust#popia; use that URL for Play Console's account deletion web resource after confirming its live wording and support contact. The privacy policy is at https://arounus.com/trust#privacy.

The native implementation includes student sign in, registration, password reset, account profile editing, module enrollment, quiz lists and answer submission, lesson lists and video playback, results, messaging, and basic community posts. The API 36 debug APK compiled, installed, and launched in BlueStacks 5. Live sign-in, home, module enrollment, quiz catalog, empty lessons state, message inbox and composer, and the account deletion request screen all loaded with a student account. The Market button opened arounus.com in BlueStacks' browser. The test account had no available quizzes or lessons, so answer submission and video playback remain unverified. Features from the full student website such as live classrooms, media tools, premium video, and richer quiz content are still outstanding.
